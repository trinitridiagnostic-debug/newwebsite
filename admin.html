Admin login

Forgot your password? On GitHub, open the newwebsite repository, delete the file admin-vault.json, and come back here to set up a new login.

First-time setup. Choose the username and password you will use from now on. Your GitHub token is locked with that password, so you only paste the token once.

How do I get a token?
  1. On GitHub open Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Name it "Trinetri admin". Set an expiry (for example 90 days).
  3. Under Repository access choose Only select repositories and pick newwebsite.
  4. Under Permissions, Repository permissions set Contents to Read and write.
  5. Generate, copy the token and paste it above. Never share it with anyone, and never paste it in a chat.

The token is locked with your password and saved as admin-vault.json in the repository. Use a long, unique password: anyone can download that file, and only the password protects the token inside.
